# DB201 — Introduction to Databases

Instructor: Dr. Maya Lindqvist  
Term: Autumn 2026  
Credits: 7.5 ECTS

This course is about storing facts so that many people can ask questions without copying spreadsheets around. We start with entity-relationship modelling, then SQL, then normalisation so your schema does not fight you in week 8.

You will use PostgreSQL in the labs. SQLite is acceptable for experiments on your laptop. Oracle is not required and will not be supported in office hours.

## Learning outcomes

After the course you should be able to:

- Draw an ER diagram that a classmate can implement without guessing cardinalities.
- Write SELECT queries with joins, grouping, and nested subqueries.
- Translate a query into relational algebra and back.
- Put a messy table into 3NF and explain which anomaly you just removed.
