# CS101 — Algorithms & Data Structures

Instructor: Dr. Maya Lindqvist  
Term: Autumn 2026  
Credits: 7.5 ECTS

This course is a first look at how to reason about running time, and how to pick a data structure without guessing. We start with asymptotic analysis, move through sorting and trees, and finish with graphs.

You will write small programs, but the point is not typing. The point is being able to say *why* an algorithm is fast enough, and what happens when the input doubles.

## What you will be able to do

- Read a loop and give a tight big-O bound.
- Implement and compare insertion sort, mergesort, and quicksort.
- Use stacks, queues, hash tables, and binary heaps as tools rather than trivia.
- Run BFS, DFS, and Dijkstra on a weighted graph and explain the difference.

Bring a laptop to the lab sessions. Pair work is allowed on the assignment unless a brief says otherwise.
